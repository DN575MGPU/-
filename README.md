4. Описание реализации. Класс CallCenter — это симуляция работы колл-центра, использующая очередь. Клиенты добавляются в конец очереди, а оператор обрабатывает звонки из начала.
   __init__()	Создаёт пустую очередь	O(1)
   
add_call(client_name)	Добавляет звонок в конец очереди	O(1)

process_call()	Удаляет звонок из начала очереди и возвращает его	O(n)

show_queue()	Выводит текущую очередь	O(n)

is_empty()	Проверяет, пуста ли очередь	O(1)

get_queue_length()	Возвращает количество звонков в очереди	O(1)
