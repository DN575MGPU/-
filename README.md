4. Текст задания: СОРТИРОВКА ШЕЛЛА И АНАЛИТИКА Задача 18. Сортировка Шелла Реализуйте функцию shell_sort(arr). Начальный шаг (gap) должен быть равен len(arr) // 2 и уменьшаться вдвое на каждой итерации (целочисленное деление).
5. Описание реализации:
Вместо сравнения соседних элементов, сравниваются элементы, находящиеся на расстоянии gap друг от друга. gap постепенно уменьшается до 1.
Алгоритм:
gap = len(arr) // 2 (начальный шаг)
Пока gap > 0:
Для каждого i от gap до n-1:
Сохранить temp = arr[i]
Сдвигать элементы arr[j - gap] вправо, пока они больше temp
Вставить temp на правильное место
gap //= 2 уменьшение шага вдвое
Сложность:
Лучший случай: O(n log n)
Средний / худший: O(n²)
