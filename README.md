Вычислите хеш по формуле: s[0]*31^(n-1) + s[1]*31^(n-2) + ... результат брать по модулю 109+7109+7

4. Описание реализации.
   Функция poly_hash_mod(s, q) вычисляет полиномиальный хеш строки s по модулю q.
Такой хеш используется для быстрого сравнения строк, поиска подстрок, проверки дубликатов и в алгоритмах типа Рабина — Карпа.
Хеш вычисляется по формуле: s[0]*31^(n-1) + s[1]*31^(n-2), где:
n — длина строки,
p — основание,
q — модуль,
ord — числовой код символа.

 Предотвращение переполнения
На каждом шаге цикла промежуточный результат берётся по модулю q, благодаря чему числа остаются в пределах ≈3×10, что безопасно для Python и не требует длинной арифметики.

Использование pow(base, exp, mod)
Для возведения 31 в степень используется встроенная функция pow() с тремя аргументами.

 Гибкость модуля
Параметр q позволяет задавать любой модуль:
маленькие (например, 7225) — для отладки,
стандартные простые (10**9+7) — для реальных задач.
